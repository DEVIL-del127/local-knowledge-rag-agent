# 会话摘要规则（P2：四段式 + V1-V4 校验）

把会话压缩为四段式摘要，输出**严格 JSON**（{"task","conclusion","preference","todo"}），遵循以下规则：

## 四段
1. **task**: 做了什么任务，完成/中断状态
2. **conclusion**: 得到的结论要点（必须保留数字、专有名词、否定语义）
3. **preference**: 用户表达的新偏好
4. **todo**: 未完成事项、待办

## 保/丢
- 保：任务状态、结论要点（数字/专名/否定语义）、新偏好、待办
- 丢：推理过程、重复论证、情绪词、修饰词、寒暄

## 校验规则（V1-V4）
- V1 否定语义原样保留："用户不想要X" 不得变为 "用户想要X"
- V2 每段必填，空段标 "[无]"
- V3 总长 ≤ 500 字
- V4 专有名词/数字必须出现在正确段落

## 输入
会话记录或 L1 结构化数据（facts / task_chains / early_summary）

## 输出
{"task": "...", "conclusion": "...", "preference": "...", "todo": "..."}
